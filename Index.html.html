Settings & data

Everything is saved in this browser only (nothing is uploaded). Each device you open the dashboard on keeps its own settings.

Calendar (Outlook)

In Outlook on the web: Settings → Calendar → Shared calendars → Publish a calendar, choose your calendar and “Can view all details”, then copy the ICS link and paste it here. If your browser blocks the direct link (common with work tenants), download the .ics file instead and drop it below, or paste its contents.

Drop an .ics file here, or

Fitbit

Export from fitbit.com → Settings → Data export (choose a date range and CSV), or use a Google Takeout / “Export your account archive” download. Drop the CSV, or the JSON files from the archive (steps-*.json, sleep-*.json, weight-*.json, resting_heart_rate-*.json). New files merge with what is already stored.

Drop Fitbit CSV / JSON files here, or
